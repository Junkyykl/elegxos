# Project "Έλεγχος Οπλιτών"

Σύστημα ελέγχου εισόδου/εξόδου και διαχείρισης υπηρεσιών οπλιτών, μέσω σάρωσης
προσωπικού QR code. Τρέχει **αποκλειστικά σε τοπικό δίκτυο (LAN)** — δεν
χρειάζεται ούτε στέλνει δεδομένα στο internet.

## Τι χρειάζεσαι να εγκαταστήσεις

1. **Node.js** (έκδοση 18 ή νεότερη) στον υπολογιστή που θα λειτουργεί ως
   server. Μπορεί να είναι ένα απλό laptop, mini PC ή Raspberry Pi μέσα στο
   στρατόπεδο.
   - Κατέβασέ το από: https://nodejs.org (επιλογή "LTS")
2. Τίποτα άλλο σε επίπεδο συσκευής — όλα τα υπόλοιπα (Express, βάση δεδομένων
   SQLite, βιβλιοθήκη QR) εγκαθίστανται αυτόματα μέσω npm, μέσα στον φάκελο
   του project.
3. Οι συσκευές των στελεχών/φανταρων (κινητά, tablet) **δεν χρειάζονται
   καμία εγκατάσταση** — απλώς έναν browser (Chrome/Safari) συνδεδεμένο στο
   ίδιο WiFi/LAN με τον server.

## Βήματα εγκατάστασης (μία φορά)

```bash
# 1. Μπες στον φάκελο του project
cd elegxos-oplitwn

# 2. Εγκατάσταση εξαρτήσεων (χρειάζεται σύνδεση internet ΜΟΝΟ αυτή τη φορά,
#    για να κατέβουν οι βιβλιοθήκες — μετά το εργαλείο τρέχει 100% offline)
npm install

# 3. Εκκίνηση του server
npm start
```

Θα δεις μήνυμα όπως:
```
Ο server τρέχει στο τοπικό δίκτυο: http://<IP-του-υπολογιστή>:3000
```

## Πώς βρίσκεις την IP του υπολογιστή-server

- **Windows**: άνοιξε cmd, γράψε `ipconfig`, βρες το "IPv4 Address" (π.χ. 192.168.1.10)
- **Mac/Linux**: γράψε `ifconfig` ή `ip a`, βρες τη διεύθυνση τύπου 192.168.x.x

## Πρόσβαση από τις συσκευές

Φρόντισε **όλες οι συσκευές (server, tablet εισόδου, κινητά στελεχών) να
είναι στο ίδιο WiFi/router**, χωρίς πρόσβαση στο internet εκτός στρατοπέδου
αν θέλεις πλήρη απομόνωση.

Στον browser κάθε συσκευής, πληκτρολόγησε:
```
http://<IP-του-υπολογιστή-server>:3000
```

- **Στέλεχος υπηρεσίας** → ανοίγει την κεντρική σελίδα με τη live λίστα
  (`/`) — βλέπει ποιος είναι μέσα/έξω, ώρες εξόδου/επιστροφής.
- **Σημείο εισόδου (tablet)** → ανοίγει τη σελίδα σάρωσης (`/scan.html`) —
  εκεί σκανάρει ο κάθε φαντάρος το QR του και γίνεται αυτόματα toggle
  είσοδος/έξοδος. Χρειάζεται πρόσβαση σε κάμερα (ο browser θα ζητήσει άδεια).
- **Καταχώρηση νέου φαντάρου + εκτύπωση QR** → `/add.html`

## Δεδομένα

Όλα τα δεδομένα αποθηκεύονται τοπικά στο αρχείο `db/elegxos.db` (SQLite).
Μπορείς να κάνεις αντίγραφο ασφαλείας αντιγράφοντας απλά αυτό το αρχείο.

## Τι μένει να χτιστεί (επόμενα βήματα)

- Οθόνη σύνδεσης (login) για στελέχη με κωδικό πρόσβασης
- Οθόνη ανάθεσης υπηρεσιών σε φαντάρους (μαζική ανάθεση, ημερολόγιο)
- Προσωπική σελίδα φαντάρου (μετά το login του) να βλέπει τις δικές του
  υπηρεσίες
- Ιστορικό/αναφορές (π.χ. εξαγωγή σε Excel για τον μήνα)
- Ασφάλεια πρόσβασης στο δίκτυο (π.χ. WiFi με κωδικό, isolation VLAN)

Πες μου ποιο θέλεις να χτίσουμε πρώτο.
